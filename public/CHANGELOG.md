# Changelog

All notable changes to ToolEasy are documented here.

## [2.8.8] — 2026-08-31

- Rebrand to **ToolEasy** (usetooleasy.com) — broader toolkit positioning beyond PDF-only
- **MCP server** for AI agents (merge/split/rotate PDF, JSON, Base64, hashing, and more)
- **pnpm** workspace migration (replaces npm)
- Proprietary licensing; removed open-source contribution/CLA/donation flows
- Simplified Docker distribution (`tooleasy:latest` only, no dual commercial/registry images)
- Utility tools: JSON formatter, Base64 encode/decode, SHA-256 hash generator

## Earlier history

Prior releases (PDF toolkit features, i18n, WASM tooling) predate the ToolEasy rebrand. See the [repository history](https://github.com/castgem/easytool/commits/main) for details.
